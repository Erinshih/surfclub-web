# 團練 LINE 自動通知小幫手

團練報名人數湊齊時，自動在「教練群組」發一則 LINE 訊息，內容包含日期、時間、浪點和參加名單（本名）。

- 每 5 分鐘檢查一次，同一團只會自動通知一次。
- 已通知的團，後台「團練管理」會顯示「📨 已自動通知教練」。
- 名單之後有變動，可以在後台按「再用 LINE 通知一次」手動補發。
- 程式放在 Google Apps Script，免費，不用綁信用卡。LINE 的金鑰只存在 Apps Script 裡，不會出現在網站上。

整個設定大約 20 分鐘，照順序做就可以。

---

## 一、建立 LINE 官方帳號

1. 打開 <https://manager.line.biz>，用自己的 LINE 帳號登入，按「建立 LINE 官方帳號」。
   - 帳號名稱可以取「衝浪社團練小幫手」，業種隨便選一個。
2. 進入剛建立的帳號，按右上角「設定」：
   - 左側「Messaging API」→「啟用 Messaging API」→ 建立一個服務提供者（名稱隨意，例如「衝浪社」）→ 同意。
   - 左側「帳號設定」→「功能切換」→「加入群組或多人聊天室」改成 **接受邀請**。
   - 左側「回應設定」→ **Webhook 開啟**、**自動回應訊息關閉**（不然機器人會在群組亂回話）。
3. 打開 <https://developers.line.biz/console>，選剛剛的服務提供者 → 點官方帳號的頻道 → 「Messaging API」分頁：
   - 拉到最下面的 **Channel access token (long-lived)**，按「Issue」，把那串金鑰複製起來（等一下會用到）。
   - ⚠️ 要複製的是「Messaging API」分頁最下面那串 **很長的 access token**（約 170 字），不是「Basic settings」分頁的 **Channel secret**（32 字）。填錯的話測試時會出現 401 錯誤。
   - 這一頁先不要關，等一下還要回來。

> ⚠️ Channel access token 等同官方帳號的密碼，不要貼到網站程式碼、群組或公開的地方。

---

## 二、建立 Google Apps Script

> 一定要用 **Firebase 專案的擁有者（或編輯者）Google 帳號** 來做，不然讀不到 Firestore。

1. 打開 <https://script.google.com>，按「新專案」，把專案名稱改成「團練通知小幫手」。
2. 左側 ⚙️「專案設定」→ 勾選 **在編輯器中顯示「appsscript.json」資訊清單檔案**。
3. 回到左側 `<>`「編輯器」：
   - 點 `程式碼.gs`（或 `Code.gs`），把裡面的內容全部刪掉，換成這個資料夾的 [Code.gs](Code.gs) 全部內容。
   - 點 `appsscript.json`，全部換成這個資料夾的 [appsscript.json](appsscript.json) 內容。
   - 按 💾 儲存。
4. 左側 ⚙️「專案設定」→ 拉到最下面「指令碼屬性」→「新增指令碼屬性」，加入這兩個：

   | 屬性 | 值 |
   |---|---|
   | `FIREBASE_PROJECT_ID` | `surfclub-web` |
   | `LINE_CHANNEL_TOKEN` | 第一步複製的 Channel access token |

5. 回到編輯器，上方的函式選單選 **previewPractices** → 按「執行」。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往 團練通知小幫手（不安全）」→「允許」。這是因為程式是你自己寫的、沒有送 Google 審核，屬於正常情況。
   - 下方「執行記錄」出現「沒有需要通知的團練。」或一則【預覽】訊息，就代表已經讀得到 Firestore 了。

---

## 三、把官方帳號邀進教練群組

1. Apps Script 右上角「部署」→「新增部署作業」→ 齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」。
2. 回到 LINE Developers 的「Messaging API」分頁：
   - **Webhook URL** 貼上剛剛的網址 → 按「Update」。
   - 打開 **Use webhook**。
   - 如果按「Verify」顯示 302 之類的錯誤可以忽略，Apps Script 本來就會這樣，不影響使用。
3. 用手機掃同一頁上方的 QR code，把官方帳號加為好友。
4. 到 **教練群組** → 右上角選單 →「邀請」→ 選官方帳號。
   - 它進群組後會回覆「這個群組的 ID：Cxxxxxxxx…」。
   - 如果沒有回覆，在群組裡輸入 `群組ID`，它就會回。
   - 還是沒回覆的話，在群組隨便傳一句話，再到 Apps Script 執行 **showGroupId**，執行記錄會顯示群組 ID。
5. 回 Apps Script「專案設定」→「指令碼屬性」，新增：

   | 屬性 | 值 |
   |---|---|
   | `LINE_GROUP_ID` | 群組 ID（C 開頭那一串） |

---

## 四、測試並開始自動執行

1. 編輯器上方選 **testLine** → 執行 → 教練群組應該會收到「✅ 團練通知小幫手設定完成！」。
2. 選 **setupTrigger** → 執行 → 之後每 5 分鐘會自動檢查一次。

完成 🎉

---

## 平常會怎麼運作

- 團練是「招募中」、報名人數 **≥ 成團人數**、還沒開始、還沒通知過 → 自動傳訊息到教練群組。
- 已經按「確認成團」或「取消」的團不會自動通知。
- 傳訊息後，那團會記下通知的時間和當時人數，後台卡片會顯示出來。

## 注意事項

- **LINE 免費額度**：官方帳號免費方案每月可以傳的訊息數有限（大約 200 則），而且是照「收到的人數」計算。例如教練群組有 6 個人，通知一次就算 6 則。實際額度以 LINE 官方帳號管理後台「方案」頁面為準。額度用完時程式會報錯，Apps Script 會寄信到你的 Gmail。
- **有錯誤時**：Apps Script 左側「執行項目」可以看每次執行的紀錄和錯誤原因，常見的有：
  - `Firestore 讀寫失敗（403）`：執行程式的 Google 帳號不是 Firebase 專案的擁有者或編輯者。
  - `LINE 傳送失敗（400）`：`LINE_GROUP_ID` 填錯，或官方帳號已經被踢出群組。
  - `LINE 傳送失敗（401）`：Channel access token 錯誤（例如填成 Channel secret）或被重新發行過。
- **換教練群組**：把官方帳號邀進新群組，輸入 `群組ID`，再更新指令碼屬性 `LINE_GROUP_ID`。
- **幹部交接**：交接時要把 Apps Script 專案共用給新幹部（或改用社團共用帳號），並確認那個帳號是 Firebase 專案成員，再重新執行一次 setupTrigger。
- **修改程式後**：如果有更新 Code.gs，要到「部署」→「管理部署作業」→ 編輯 →「版本：新版本」→「部署」，Webhook 才會用到新程式。排程（checkPractices）則會直接用最新的程式。
